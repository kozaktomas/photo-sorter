# Shift-click range selection on PhotoGrid

Extend `usePhotoSelection` to support contiguous range selection so users can pick large batches in two clicks instead of N.

## Requirements

- Shift-click on a `PhotoCard` while another card is already selected: select every photo from the most-recently-toggled card to the shift-clicked card in the current grid order (inclusive).
- Plain click continues to toggle one photo and updates the "anchor" used for the next shift-click.
- Ctrl/Cmd-click toggles a single card without affecting the anchor.
- `Ctrl/Cmd+A` selects every photo currently rendered in the grid view. `Esc` clears the selection.
- Works on every page that uses `PhotoGrid` with selection enabled: `Photos`, `SimilarPhotos`, `Expand`, `Duplicates`, `Trash`, `SmartAlbumDetail`.
- No visual change to PhotoCard — only the click handler behavior changes. The existing `BulkActionBar` continues to reflect the count.

## Implementation Notes

- Track the anchor index inside `usePhotoSelection` state. Range computation should use the photo array passed to the grid (not random sort), so semantics match what the user sees.
- Mobile/touch: shift-click isn't reachable, so behavior on touch devices stays unchanged (single toggle).
- Update unit tests for `usePhotoSelection` if any exist.
