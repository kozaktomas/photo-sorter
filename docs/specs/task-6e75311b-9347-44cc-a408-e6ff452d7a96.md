# Frontend: switch API client to native endpoints

Rewire the React frontend (`web/`) to use only the photo-sorter's own endpoints — no implicit PhotoPrism URL knowledge. All HTTP routes already exist (rewritten by earlier tasks); this task fixes the few places where the frontend talks to PhotoPrism directly (thumbnails, download URLs) and reshapes any payloads that drifted.

## Requirements

### Search for PhotoPrism URL references

Find every place in `web/src/` that references `photoprism`, `pp-`, or constructs a URL outside of `client.ts`. Likely hot spots:
- `web/src/api/client.ts` — `getThumbnailUrl(uid, size)`, `getDownloadUrl(uid)`.
- `web/src/components/PhotoCard.tsx`, `PhotoWithBBox.tsx`, `LazyImage.tsx`.
- Anywhere with `/api/v1/photoprism/...` or a manual `/p/...` URL.

Update each one to point to the native routes:
- Thumbs: `GET /api/v1/photos/{uid}/thumb/{size}`.
- Download: `GET /api/v1/photos/{uid}/download`.

Cookie auth is unchanged — the browser keeps sending the session cookie.

### Type alignment

Walk `web/src/types/index.ts` `Photo` shape and align field names with the new backend response (`file_path`, `file_hash`, `taken_at`, `lat`, `lng`, `archived_at`, `uploaded_by` etc.). Drop any fields that no longer exist in the native response.

### Trash page

Add `web/src/pages/Trash/Trash.tsx`:
- Route `/trash` behind the auth guard.
- Reuses the existing `PhotoGrid` + `usePhotoSelection` hook.
- Header has two bulk actions: "Restore" and "Purge" (purge is admin-only — hide for other roles).
- Calls `GET /api/v1/photos/trash`, `POST /api/v1/photos/batch/restore`, `POST /api/v1/photos/batch/purge`.

Add a small "Trash" link to the layout sidebar.

### Near-duplicate UI

When the upload SSE stream emits a `near_duplicates` event (added by the duplicate-detection task), surface a small modal at the end of the upload offering "Keep both" (default — already uploaded) or "Delete just-uploaded copy". Delete uses the existing batch-archive endpoint.

### Lint + typecheck

- `cd web && npx tsc --noEmit && npm run lint` passes.
- `make build` succeeds.

### Manual sanity

- Login, view a photo → thumb loads from `/api/v1/photos/.../thumb/...` (verify in network tab).
- Trash page shows archived photos.
- Upload + near-duplicate detection surfaces the dialog.
