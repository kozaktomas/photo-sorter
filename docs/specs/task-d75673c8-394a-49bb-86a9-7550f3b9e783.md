# Global keyboard shortcuts with `?` cheatsheet overlay

Add app-wide keyboard shortcuts (today only BookEditor has them via `useBookKeyboardNav`) and a discoverable `?` overlay that lists them.

## Requirements

- New `useGlobalShortcuts` hook installed at the `Layout` level. Must noop when the focus is inside an `input`, `textarea`, or `contenteditable` element so it never steals typing.
- Pressing `?` (Shift+/) anywhere opens a modal listing every active shortcut grouped by page (Global / Photos grid / PhotoDetail / BookEditor). Esc or click-outside closes it.
- Photos grid shortcuts: `j` / `k` move focus to next/previous card, `Space` toggles selection of the focused card, `Enter` opens detail.
- PhotoDetail shortcuts: `j` / `k` (or `ArrowLeft` / `ArrowRight`) navigate prev/next photo, `f` toggles favorite, `e` opens edit modal, `a` archives (with confirm), `Esc` closes.
- All shortcut strings + descriptions live in one registry module so the `?` modal renders from the same source the hook reads from.
- i18n: shortcut descriptions go through the existing i18n setup (cs + en).

## Implementation Notes

- Reuse the modal styling from existing dialogs (`ConfirmDialog` / Book editor `KeyboardShortcutsHelp` pattern).
- Don't refactor BookEditor's existing `useBookKeyboardNav` — leave it as-is, just surface its shortcuts in the global `?` overlay.
- Verify no collision with browser/OS shortcuts (avoid bare `Ctrl+S`, `Ctrl+F`, etc.).
