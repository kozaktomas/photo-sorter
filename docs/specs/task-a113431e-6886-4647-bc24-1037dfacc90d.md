# Remove internal/photoprism package + env vars

Final cleanup once all handlers and CLI commands are native: delete the PhotoPrism client package, remove the env vars and config plumbing, and make sure nothing references the old client.

DO NOT run this task while any handler still calls `pp.*`. Verify first.

## Requirements

### Pre-check

Before deleting anything, run:

```bash
grep -rn 'pp\.\|photoprism\.New\|photoprism\.Client\|"internal/photoprism"' \
  --include='*.go' \
  cmd/ internal/web/ internal/sorter/ internal/mcp/
```

If anything is returned, stop and report the call sites in the task notes — do not proceed with deletion. A genuine "needs review" outcome is preferable to a half-removed package.

### Deletion

When the grep is clean:

1. Delete the entire `internal/photoprism/` directory (including tests and swagger.yaml).
2. Remove the `photoprism` field from any handler struct, the wiring in `internal/web/router.go`, and the middleware helper `MustGetPhotoPrism` from `internal/web/middleware/`.
3. Remove `photoprism.Client` references from `internal/sorter/` if any remain (the AI sort job should call `LabelWriter.EnsureLabel` + `PhotoWriter.UpdatePhoto` after earlier refactors).
4. Remove the corresponding CLI commands that wrapped PhotoPrism actions: `cmd/upload.go` (replaced by native upload + new `migrate-from-photoprism`), `cmd/albums.go` (replace with a native album-list command if not already), `cmd/labels.go` (native), `cmd/move.go` (native).
5. Migrate `cmd/serve.go` to drop the PhotoPrism client initialization.

### Config

Remove from `internal/config/config.go`:
- `PhotoprismURL`, `PhotoprismUsername`, `PhotoprismPassword`, `PhotoprismDomain`, `PhotoprismDatabaseURL`.

Update `.env.dev` and `.env.example` (if present) to drop the `PHOTOPRISM_*` keys.

### CLAUDE.md

Update `CLAUDE.md` to remove the PhotoPrism API auth section, the `PHOTOPRISM_*` env var documentation, and the "Direct PhotoPrism API Auth" section. Keep a short note that PhotoPrism is no longer a runtime dependency.

### Tests

Run `make test` and fix any compile errors. Update tests that mocked the PhotoPrism client — they should be either deleted (no longer needed) or refactored to use the native repositories.

### go.mod

After removing the package, run `go mod tidy` and commit the updated `go.mod` + `go.sum`.

## Verification

- `make test` passes.
- `make lint`, `make build-go` pass.
- `grep -rn 'photoprism' --include='*.go' .` returns only docstrings / docs references, no live code.
