# Refresh docs/cli-reference.md

`docs/cli-reference.md` documents every CLI command and flag. Bring it in sync with the Cobra commands actually registered in the binary.

## Scope

- File to edit: `docs/cli-reference.md` only.
- Source of truth: every file under `cmd/` (Cobra command definitions + flags). Cross-reference with `main.go` for the root command wiring.

## What to verify and update

1. **Command inventory** — enumerate every Cobra command defined in `cmd/` and verify it has a section in `docs/cli-reference.md`. Conversely, remove any documented command that no longer exists.
2. **Flags** — for each command, verify the documented flags match the flag definitions in code (name, shorthand, default, description).
3. **Recently added or changed commands** — pay special attention to:
   - `users` (list / create / set-password / delete; `--role` flag; `--yes` for delete; TTY prompt requirement; audit log entries).
   - `db-export` and `db-import` (pg_dump / pg_restore wrappers; `-o` / `-i`; `--yes` to skip prompts; what is included and excluded).
   - `backup` (bundles DB dump + originals into a timestamped directory; archival of originals is operator's responsibility).
   - `migrate-from-photoprism`, `migrate-verify` (with `--strict`), `migrate-remap-references`.
   - `cache build-thumbs` (concurrency, sizes filter, only-missing toggle, limit, photo-uid, JSON output) and `cache compute-phashes`, `cache compute-eras`.
   - `photo info`, `photo match`, `photo similar`, `photo clear-faces`.
   - `sort` (provider, batch, individual-dates, force-date, concurrency, limit, dry-run).
   - `labels` (list with sort + min-photos; `labels delete`).
   - `upload` (recursive flag, label repetition).
   - `move`, `count`, `version`, `serve` (with port/host overrides).
4. **Examples** — every example shown must reflect a real invocation. Update outdated invocations.
5. **Cross-references** — point to `docs/API.md` for the equivalent REST surface where relevant; point to `docs/backup.md` for the DR runbook.
6. **External binaries** — call out that `exiftool`, `heif-convert`, and `dcraw` must be installed for the upload pipeline (the Docker image bundles them; for dev, OS package manager).

## Rules

- Code is the source of truth. Read the Cobra command definitions before documenting flags.
- Do not invent commands, flags, defaults, or behavior. Grep before you write.
- Keep the existing section structure (one section per top-level command, sub-commands nested).
- Preserve consistent formatting for flag tables / lists across the document.
- Where behavior is non-obvious (e.g. `--force-date` semantics in `sort`, what `backup` includes vs excludes), state it explicitly.

## Done when

- Every command in `cmd/` is documented in `docs/cli-reference.md`.
- Every flag listed matches the Cobra definitions.
- Removed or renamed commands are no longer present.
- Recent additions (users, db-export, db-import, backup, migrate-verify, migrate-remap-references, cache build-thumbs) are documented with accurate flag tables and examples.
