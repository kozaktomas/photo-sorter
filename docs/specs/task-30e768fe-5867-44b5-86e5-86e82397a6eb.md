# Users table + role model

Add the user repository (backed by the `users` table introduced in the native schema migration) and a thin `internal/auth` package with bcrypt helpers. This task does NOT touch login/session handlers — those move in a separate task.

## Requirements

### Files

- `internal/auth/auth.go` — bcrypt + role constants.
- `internal/database/types.go` — `User` type.
- `internal/database/repository.go` — `UserReader`, `UserWriter` interfaces.
- `internal/database/postgres/users.go` — implementation.
- `internal/database/postgres/users_test.go` — tests.

### Auth package

```go
package auth

const (
    RoleAdmin  = "admin"
    RoleEditor = "editor"
    RoleViewer = "viewer"
)

func HashPassword(plain string) (string, error)         // bcrypt cost 12
func CheckPassword(plainAttempt, hash string) bool      // constant-time
func IsValidRole(role string) bool
func HasWriteAccess(role string) bool                   // admin || editor
func IsAdmin(role string) bool
```

Add `golang.org/x/crypto/bcrypt` to `go.mod` if not present (it's likely a transitive dep already; explicitly require it).

### User type

```go
type User struct {
    UID         string
    Username    string
    DisplayName string
    Email       string
    Role        string
    Disabled    bool
    CreatedAt   time.Time
    UpdatedAt   time.Time
    LastLoginAt *time.Time
}

type UserWithSecret struct {
    User
    PasswordHash string
}
```

`UserWithSecret` is for internal use only (login flow) — never serialized to API responses.

### Repository

```go
type UserReader interface {
    GetUser(ctx context.Context, uid string) (*User, error)
    GetUserByUsername(ctx context.Context, username string) (*UserWithSecret, error)
    ListUsers(ctx context.Context) ([]User, error)
    CountUsers(ctx context.Context) (int, error)
}

type UserWriter interface {
    CreateUser(ctx context.Context, u *UserWithSecret) error
    UpdateUser(ctx context.Context, u *User) error
    SetPassword(ctx context.Context, uid, newHash string) error
    SetDisabled(ctx context.Context, uid string, disabled bool) error
    TouchLastLogin(ctx context.Context, uid string) error
    DeleteUser(ctx context.Context, uid string) error
}
```

UID format: `"u" + 16 random base32 lowercase chars`.

Username uniqueness is enforced by the `UNIQUE` constraint — surface the violation as a typed error `ErrUsernameTaken` exported by `internal/database`.

### Bootstrap admin

When the server starts, if `CountUsers() == 0` the application should auto-create an admin user using env vars `BOOTSTRAP_ADMIN_USERNAME` and `BOOTSTRAP_ADMIN_PASSWORD`. Implement this in `internal/auth/bootstrap.go`:

```go
func BootstrapAdmin(ctx context.Context, reader database.UserReader, writer database.UserWriter, cfg config.Config) error
```

If the env vars are missing AND no users exist, log a clear `WARN` line and continue — the admin will create the first user manually later. Wire the call into the server startup path (in `cmd/serve.go` or wherever DB is initialised, AFTER migrations run, BEFORE the HTTP server starts).

### Tests

- Hash + check round-trip.
- Wrong password fails the check.
- Create + GetByUsername returns the secret.
- Username uniqueness → `ErrUsernameTaken`.
- Disable + TouchLastLogin update the row.
- `BootstrapAdmin` is idempotent: second call with existing users is a no-op.

## Verification

- `make test` passes.
- `make lint`, `make build-go` pass.
- Server starts with `BOOTSTRAP_ADMIN_USERNAME` + `BOOTSTRAP_ADMIN_PASSWORD` set → exactly one admin user exists in the DB after startup. Second start is a no-op.
