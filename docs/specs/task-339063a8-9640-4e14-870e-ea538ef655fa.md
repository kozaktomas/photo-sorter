# Documentation update

After the PhotoPrism dependency is gone, sweep through the docs and bring them up to date with the native photo management story. Several files reference PhotoPrism extensively — those references need to either disappear or be re-framed as historical context.

## Requirements

### Files to update

- `CLAUDE.md` — top-level instructions for AI agents. Drop the PhotoPrism API auth section, the `PHOTOPRISM_*` env vars, and the "PhotoPrism Client Middleware" section. Add the new env vars: `STORAGE_ORIGINALS_PATH`, `STORAGE_CACHE_PATH`, `BOOTSTRAP_ADMIN_USERNAME`, `BOOTSTRAP_ADMIN_PASSWORD`, `TRASH_RETENTION_DAYS`, `DUPLICATE_PHASH_MAX_DIFF`, `DUPLICATE_EMBEDDING_MAX_DIST`, `DUPLICATE_CHECK_ENABLED`. Drop `PHOTOPRISM_DATABASE_URL`. Add a paragraph explaining the storage layout (originals/YYYY/MM, cache/thumb/aa/bb/cc/hash_size.jpg).

- `README.md` — high-level project description. Remove "wraps PhotoPrism" framing; lead with "self-contained photo management". Update the feature list. Document the `migrate-from-photoprism` and `backup` commands.

- `docs/architecture.md` — replace the PhotoPrism client diagrams and data-flow descriptions with the native flow. Add a section on the `storage`, `exif`, `thumb`, `imgconvert`, `photopipe` packages.

- `docs/cli-reference.md` — add `migrate-from-photoprism`, `migrate-verify`, `backup`, `cache build-thumbs`, `cache compute-phashes`. Drop or rewrite any commands that exclusively called PhotoPrism.

- `docs/web-ui.md` — update the page list (add Trash, Settings, Capture). Replace any mention of "calls PhotoPrism" with the native flow.

- `docs/API.md` — refresh the endpoint list: add `/api/v1/photos/trash`, `/api/v1/photos/batch/restore`, `/api/v1/photos/batch/purge`, `/api/v1/photos/{uid}/exif`, `/api/v1/users/*`, `/api/v1/me/*`. Drop endpoints that no longer exist. Note the change in auth (native, not PhotoPrism credentials).

- `docs/markers.md` — update for the native `markers` table; explain how it differs from PhotoPrism's `markers` table mappings. Remove direct-DB-access notes for MariaDB.

- `docs/testing-environment.md` — remove PhotoPrism + MariaDB sections. Document the bootstrap-admin env vars and the storage path env vars.

- `docs/era-estimation.md`, `docs/photo-book.md`, `docs/hnsw-architecture.md` — light review. Remove any straggling PhotoPrism references.
