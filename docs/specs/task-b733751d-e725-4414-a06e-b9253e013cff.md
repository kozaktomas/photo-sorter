# Refresh docs/web-ui.md

`docs/web-ui.md` is the comprehensive guide to the React frontend (currently ~1 230 lines). Bring it in sync with the actual pages, hooks, components, and user-facing features in `web/src/`.

## Scope

- File to edit: `docs/web-ui.md` only.
- Source of truth: source under `web/src/` (pages, hooks, components, i18n locales). Cross-reference with `internal/web/` for the backend endpoints each page calls.

## What to verify and update

1. **Page inventory** — every page directory or component under `web/src/pages/` must be documented (Dashboard, Albums, Photos, PhotoDetail, Labels, LabelDetail, Login, Outliers, Process, SimilarPhotos, SubjectDetail, TextSearch, Analyze, Faces, Recognition, Duplicates, Compare, Books, BookEditor, Slideshow, SuggestAlbums, SmartAlbums, Upload, Expand, etc.). Conversely, drop sections about pages that no longer exist.
2. **Recently added / changed features** — verify each is described with what the user sees and what backend it touches:
   - **Slideshow + TV / presentation mode** (`Slideshow/`): wake lock, Ken Burns effect, caption overlay, TV control bar.
   - **Photos page**: map + timeline scrubber with bidirectional filtering, date-range + GPS bbox filters, Czech-aware text search box, sort/limit controls, archived/private/favorite toggles.
   - **Photo detail**: non-destructive edit panel (crop, rotate, brightness, contrast) and the revert-to-original action; EXIF editor; album / book memberships; era estimate; face assignment.
   - **Smart Albums**: list page, modal, detail page; saved filters re-evaluate live; UID immutable across renames.
   - **Album share links**: mint UI on album page, public consumer page (password gate, expiry messaging, photo grid, downloads, thumbnails) under `/share/<slug>`.
   - **Mobile capture / PWA**: `/capture` page with native camera; installable manifest behavior.
   - **Upload page**: mobile-friendly upload flow with native camera capture; SSE progress; near-duplicate warnings.
   - **Trash view**: archived photos browser; restore + purge actions (purge is admin-only).
   - **User management** Settings page: list, create, set-password, role change, disable, delete; "last admin" guard messaging.
   - **Audit log** Settings page (if present): filters, joined username, batch-action collapsing.
   - **Book editor**: typography tab (fonts, sizes, color, body padding, captions opacity), texts tab (T1/T2/T3 detection, markdown rendering), duplicates tab, preview tab, export progress modal with photo_quality selector, hide_page_number toggle, captions/contents slot handling, drag photos between sections, page minimap, spread view.
3. **Shared hooks** — list under `web/src/hooks/` must be accurate (`useAuth`, `useBookKeyboardNav`, `useFaceApproval`, `usePhotoSelection`, `useSSE`, `useSubjectsAndConfig`). Add new ones, drop removed ones.
4. **Shared components** — list under `web/src/components/` must be accurate.
5. **i18n** — confirm Czech + English locales under `web/src/i18n/locales/{cs,en}/` and the language switcher.
6. **Routing** — verify documented routes match the router config; include the public share routes.
7. **API client** — point to `web/src/api/client.ts` for the typed wrapper.

## Rules

- Code is the source of truth. Open the page component before describing it.
- Do not invent pages, hooks, components, or features. Grep before you write.
- Preserve the existing section structure; do surgical edits.
- Where helpful, link forward to `docs/API.md` for the backend endpoint and to feature-specific docs (`docs/photo-book.md`, `docs/markers.md`).
- Avoid duplicating endpoint documentation; describe behavior at the UX level and link.

## Done when

- Every page, shared hook, and shared component in `web/src/` is documented or intentionally omitted (e.g. trivial wrappers).
- Recent features (slideshow TV mode, map + timeline, smart albums, share links, photo edits, mobile capture, trash, user management) are described from the user's perspective.
- Removed or renamed pages are gone from the doc.
- Backend endpoint references match `docs/API.md`.
