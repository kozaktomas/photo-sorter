# HEIC/RAW format conversion

Create `internal/imgconvert` — a package that wraps external binaries (`heif-convert`, `dcraw`) to convert HEIC/HEIF and RAW formats to intermediate JPEG so the existing thumbnail generator (`internal/thumb`) and `image.Decode` paths can handle them.

This task is independent of upload, storage, DB. It's a pure utility that takes a file path and returns either the original (already-decodable) or a temp JPEG.

## Requirements

### Package layout

```
internal/imgconvert/
  imgconvert.go     // public API + format detection
  heif.go           // heif-convert wrapper
  raw.go            // dcraw wrapper
  imgconvert_test.go
```

### Public API

```go
// EnsureDecodable returns a path to a file that Go's image.Decode can handle.
// If the input is already JPEG/PNG/WebP, returns (input, nil, nil).
// If the input is HEIC/HEIF, RAW (CR2/NEF/ARW/DNG/RAF/ORF/RW2), invokes the
// appropriate external tool to produce a temp JPEG and returns its path plus
// a cleanup function the caller must defer.
func EnsureDecodable(ctx context.Context, srcPath string) (path string, cleanup func(), err error)

// IsSupportedFormat returns whether sorter can ingest a file with this extension.
func IsSupportedFormat(ext string) bool

// DetectFormat returns one of: "jpeg", "png", "webp", "heic", "raw", "unknown".
func DetectFormat(path string) string
```

### Format detection

By extension (lowercased), then verified by magic bytes:
- `jpeg`: `.jpg`, `.jpeg`
- `png`: `.png`
- `webp`: `.webp`
- `heic`: `.heic`, `.heif`
- `raw`: `.cr2`, `.cr3`, `.nef`, `.arw`, `.dng`, `.raf`, `.orf`, `.rw2`, `.pef`, `.srw`

`IsSupportedFormat` returns true for all of the above.

### HEIC conversion

```bash
heif-convert -q 92 <src> <tmp.jpg>
```

- 30-second timeout via `exec.CommandContext`.
- Temp file in `os.TempDir()` with a random name and `.jpg` suffix.
- If `heif-convert` is not in PATH, return error wrapping `ErrConverterMissing` (a sentinel exported by this package).

### RAW conversion

```bash
dcraw -c -w -h <src> > <tmp.ppm>
```

`-c` writes to stdout, `-w` uses camera white balance, `-h` is half-size for speed (full size is too slow for upload).

Then pipe the PPM through `pnmtojpeg` (or decode PPM in Go and re-encode JPEG — pnmtojpeg may not be installed). Implement the in-Go PPM decode (it's a trivial header + raw RGB stream) and use `image/jpeg.Encode` with quality 90.

60-second timeout.

If `dcraw` is missing, return `ErrConverterMissing`.

### Cleanup contract

Returned `cleanup` is non-nil ONLY when a temp file was created. It MUST be safe to call multiple times. When the input is already decodable, `cleanup` is `func() {}` (no-op).

### Tests

- JPEG input → returns same path, no-op cleanup.
- Format detection by extension table.
- Magic-byte detection for JPEG (FF D8 FF), PNG (89 50 4E 47), HEIC (ftyp box at offset 4 + brand `heic`/`heix`/`mif1`).
- HEIC/RAW conversion tests use `t.Skip` when the binary is missing — CI without converters still passes.
- Provide a tiny test HEIC and a tiny CR2 in `testdata/` if licensing allows; otherwise document that the test skips.
