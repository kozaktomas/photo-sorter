# Mobile-Friendly Upload Page with Camera Capture

Make the existing photo upload page usable from a phone, including capturing photos directly from the device camera. No PWA work; no service worker; no share-target — just responsive UI and HTML capture.

## Requirements

- Responsive layout for `/upload`: the page must work cleanly at 360px viewport width.
- Add a "Take photo" button that opens the device camera directly via `<input type="file" accept="image/*" capture="environment">`. On desktop this button can be hidden (it behaves identically to a file picker on desktop browsers).
- The existing "Choose files" button must allow multi-select from the gallery on mobile (verify the HTML `multiple` attribute is set).
- Touch targets: buttons, label/album combobox, and the drop zone must be at least 44px tall on mobile.
- Drop zone: still visible on mobile but smaller; the tap target opens the file picker. The "drag and drop" hint text should hide on touch devices.
- Progress UI (existing upload job + SSE flow): per-photo progress list must scroll cleanly on mobile — constrain max-height with internal scroll.
- Bulk upload continues to use the existing `POST /api/v1/upload/job` flow — no backend changes.

## UI Details

- Below 768px viewport:
  - Stack album/label selectors vertically.
  - "Take photo" and "Choose files" buttons are full-width and stacked vertically.
  - Hide the drag-and-drop hint text.
- Above 768px:
  - Existing layout preserved. Hide the "Take photo" button.

## Edge Cases

- iOS Safari handling of `capture="environment"` varies — don't try to work around browser quirks. Both gallery and camera paths must produce uploadable files.
- Single-file capture (camera typically returns one photo at a time) must work with the existing job flow as a 1-file batch.
- Large uploads from a phone: existing job flow handles it; just verify the progress bar doesn't visually overflow.

## Out of Scope

- PWA installation, service worker, web manifest changes.
- Background upload while the phone is locked.
- Share target (sharing from gallery into photo-sorter).
