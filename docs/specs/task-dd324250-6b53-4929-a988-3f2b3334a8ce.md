# Thumbnail generator service

Create `internal/thumb` — a package that takes a source image file and produces JPEG thumbnails in the standard PhotoPrism size set, writing them through `internal/storage.WriteThumb`. This task only handles JPEG, PNG, WebP source inputs. HEIC and RAW conversion is a separate task and is layered on top of this one.

## Requirements

### Package layout

```
internal/thumb/
  thumb.go        // public API, size registry
  resize.go       // image decode + resize + JPEG encode
  thumb_test.go
```

### Size registry

Define a fixed map of named sizes (longest side, in pixels):

| Name | Max longest side | Quality | Mode |
|------|------------------|---------|------|
| `fit_720` | 720 | 90 | fit |
| `fit_1280` | 1280 | 90 | fit |
| `fit_1920` | 1920 | 90 | fit |
| `fit_2560` | 2560 | 88 | fit |
| `fit_3840` | 3840 | 88 | fit |
| `fit_7680` | 7680 | 85 | fit |
| `tile_50` | 50 | 80 | crop-square |
| `tile_100` | 100 | 80 | crop-square |
| `tile_224` | 224 | 85 | crop-square |
| `tile_500` | 500 | 85 | crop-square |

`fit` preserves aspect ratio (no upscaling). `crop-square` center-crops to a square then resizes.

### Public API

```go
type Source struct {
    Path        string       // path on disk
    Orientation int          // EXIF 1-8 (apply rotation/flip on decode)
}

// Generate writes one thumb to storage and returns the relative path.
func Generate(src Source, sizeName string, store *storage.Storage, fileHash string) (relPath string, err error)

// GenerateAll iterates all sizes; missing ones are produced, existing ones are skipped.
// Returns the relative paths of all sizes that now exist.
func GenerateAll(src Source, store *storage.Storage, fileHash string) (map[string]string, error)
```

`storage.Storage` and the size registry are read-only — this package never mutates them.

### Implementation

- Decode using `image.Decode` (registered: jpeg, png, webp via `golang.org/x/image/webp`).
- Apply orientation: rotate/flip the decoded image based on EXIF orientation 1-8 (write a small helper switch — there are 8 cases).
- Resize using `golang.org/x/image/draw.CatmullRom` for downscale quality.
- Encode as JPEG with the per-size quality.
- Skip if `store.ThumbExists(rel)` already true.
- Concurrency: `GenerateAll` runs sizes sequentially. Concurrency at upload level happens elsewhere.

### Tests

- A sample 4000×3000 JPEG → all 10 thumbnails produced, each within the size bound.
- Orientation 6 (90° CW) source → resulting thumb has swapped width/height.
- Re-running `GenerateAll` is a no-op (no rewrites).
- Unknown size name → error.
