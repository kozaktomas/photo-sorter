# DB schema for native photo management

Add a new Postgres migration that introduces the schema for managing photos, users, albums, labels, faces, markers and subjects natively in photo-sorter, so that PhotoPrism can later be retired. The existing `embeddings`, `faces` (512-dim ResNet100 cache), `era_embeddings`, `sessions`, `photo_books`, `text_versions`, `text_check_results` tables stay as-is.

This task ONLY creates the schema. Code that uses it is in later tasks.

## Requirements

Create a new migration file in `internal/database/postgres/migrations/` (next free number, currently 031 is the last one — use 032) that creates the following tables. All new tables use `VARCHAR(32)` for UIDs (matching the existing PhotoPrism-style UIDs, e.g. starting with `p` for photo, `a` for album, `s` for subject, etc.) — generated by the application, not the DB.

### `users`
- `uid VARCHAR(32) PRIMARY KEY`
- `username VARCHAR(64) NOT NULL UNIQUE`
- `display_name VARCHAR(255) NOT NULL DEFAULT ''`
- `email VARCHAR(255) NOT NULL DEFAULT ''`
- `password_hash TEXT NOT NULL` (bcrypt)
- `role VARCHAR(16) NOT NULL CHECK (role IN ('admin','editor','viewer'))`
- `disabled BOOLEAN NOT NULL DEFAULT false`
- `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
- `updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
- `last_login_at TIMESTAMPTZ`

### `photos`
The main photo metadata table. Replaces the PhotoPrism `photos` table.
- `uid VARCHAR(32) PRIMARY KEY`
- `file_hash VARCHAR(64) NOT NULL UNIQUE` (SHA256 of primary file, used for dedup)
- `file_path TEXT NOT NULL` (relative path inside originals dir, e.g. `2024/06/IMG_1234.jpg`)
- `file_name VARCHAR(255) NOT NULL` (original filename)
- `file_size BIGINT NOT NULL`
- `file_mime VARCHAR(64) NOT NULL` (e.g. `image/jpeg`, `image/heic`)
- `file_width INT NOT NULL DEFAULT 0`
- `file_height INT NOT NULL DEFAULT 0`
- `file_orientation INT NOT NULL DEFAULT 1` (EXIF orientation 1-8)
- `taken_at TIMESTAMPTZ` (nullable — may be unknown)
- `taken_at_source VARCHAR(16) NOT NULL DEFAULT 'unknown'` — one of `exif`, `filename`, `manual`, `ai`, `unknown`
- `title VARCHAR(255) NOT NULL DEFAULT ''`
- `description TEXT NOT NULL DEFAULT ''`
- `notes TEXT NOT NULL DEFAULT ''`
- `lat DOUBLE PRECISION` (nullable)
- `lng DOUBLE PRECISION` (nullable)
- `altitude DOUBLE PRECISION`
- `camera_make VARCHAR(64) NOT NULL DEFAULT ''`
- `camera_model VARCHAR(128) NOT NULL DEFAULT ''`
- `lens_model VARCHAR(128) NOT NULL DEFAULT ''`
- `iso INT`
- `aperture DOUBLE PRECISION`
- `exposure VARCHAR(32) NOT NULL DEFAULT ''` (e.g. `1/250`)
- `focal_length DOUBLE PRECISION`
- `exif JSONB NOT NULL DEFAULT '{}'::jsonb` — raw EXIF for future use
- `favorite BOOLEAN NOT NULL DEFAULT false`
- `private BOOLEAN NOT NULL DEFAULT false`
- `archived_at TIMESTAMPTZ` (nullable — soft-delete / trash)
- `uploaded_by VARCHAR(32) REFERENCES users(uid) ON DELETE SET NULL`
- `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
- `updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`

Indexes:
- `taken_at DESC`
- `archived_at` partial (`WHERE archived_at IS NOT NULL`)
- GIN index on `exif`
- BTREE on `lat, lng` for bbox queries

### `photo_files`
A photo may have multiple files (e.g. RAW + JPEG sidecar, HEIC + JPEG, edited variants — "stacks" in PhotoPrism terminology).
- `id BIGSERIAL PRIMARY KEY`
- `photo_uid VARCHAR(32) NOT NULL REFERENCES photos(uid) ON DELETE CASCADE`
- `file_path TEXT NOT NULL` (relative to originals dir)
- `file_hash VARCHAR(64) NOT NULL`
- `file_size BIGINT NOT NULL`
- `file_mime VARCHAR(64) NOT NULL`
- `is_primary BOOLEAN NOT NULL DEFAULT false`
- `role VARCHAR(16) NOT NULL DEFAULT 'original'` — `original` / `sidecar` / `edited`
- `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
- UNIQUE (`photo_uid`, `file_path`)
- Partial unique index: only one `is_primary = true` per `photo_uid`

### `albums`
- `uid VARCHAR(32) PRIMARY KEY`
- `slug VARCHAR(255) NOT NULL UNIQUE`
- `title VARCHAR(255) NOT NULL`
- `description TEXT NOT NULL DEFAULT ''`
- `type VARCHAR(16) NOT NULL DEFAULT 'album' CHECK (type IN ('album','folder','moment','state','month'))`
- `cover_photo_uid VARCHAR(32) REFERENCES photos(uid) ON DELETE SET NULL`
- `favorite BOOLEAN NOT NULL DEFAULT false`
- `private BOOLEAN NOT NULL DEFAULT false`
- `order_by VARCHAR(16) NOT NULL DEFAULT 'newest'`
- `created_by VARCHAR(32) REFERENCES users(uid) ON DELETE SET NULL`
- `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
- `updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`

### `album_photos`
- `album_uid VARCHAR(32) NOT NULL REFERENCES albums(uid) ON DELETE CASCADE`
- `photo_uid VARCHAR(32) NOT NULL REFERENCES photos(uid) ON DELETE CASCADE`
- `sort_order INT NOT NULL DEFAULT 0`
- `added_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
- PRIMARY KEY (`album_uid`, `photo_uid`)
- Index on `photo_uid` for reverse lookup

### `labels`
- `uid VARCHAR(32) PRIMARY KEY`
- `slug VARCHAR(255) NOT NULL UNIQUE`
- `name VARCHAR(255) NOT NULL`
- `priority INT NOT NULL DEFAULT 0`
- `favorite BOOLEAN NOT NULL DEFAULT false`
- `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
- `updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`

### `photo_labels`
- `photo_uid VARCHAR(32) NOT NULL REFERENCES photos(uid) ON DELETE CASCADE`
- `label_uid VARCHAR(32) NOT NULL REFERENCES labels(uid) ON DELETE CASCADE`
- `source VARCHAR(16) NOT NULL DEFAULT 'manual'` (`manual` / `ai` / `import`)
- `uncertainty INT NOT NULL DEFAULT 0` (0-100, lower = more certain)
- `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
- PRIMARY KEY (`photo_uid`, `label_uid`)

### `subjects`
- `uid VARCHAR(32) PRIMARY KEY`
- `slug VARCHAR(255) NOT NULL UNIQUE`
- `name VARCHAR(255) NOT NULL`
- `type VARCHAR(16) NOT NULL DEFAULT 'person' CHECK (type IN ('person','pet','other'))`
- `favorite BOOLEAN NOT NULL DEFAULT false`
- `private BOOLEAN NOT NULL DEFAULT false`
- `notes TEXT NOT NULL DEFAULT ''`
- `cover_photo_uid VARCHAR(32) REFERENCES photos(uid) ON DELETE SET NULL`
- `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
- `updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`

### `markers`
Face/region markers on photos. Replaces the PhotoPrism `markers` table.
- `uid VARCHAR(32) PRIMARY KEY`
- `photo_uid VARCHAR(32) NOT NULL REFERENCES photos(uid) ON DELETE CASCADE`
- `subject_uid VARCHAR(32) REFERENCES subjects(uid) ON DELETE SET NULL`
- `type VARCHAR(16) NOT NULL DEFAULT 'face' CHECK (type IN ('face','label'))`
- `x DOUBLE PRECISION NOT NULL` (relative 0-1, top-left of bbox)
- `y DOUBLE PRECISION NOT NULL`
- `w DOUBLE PRECISION NOT NULL`
- `h DOUBLE PRECISION NOT NULL`
- `score INT NOT NULL DEFAULT 0`
- `invalid BOOLEAN NOT NULL DEFAULT false`
- `reviewed BOOLEAN NOT NULL DEFAULT false`
- `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
- `updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
- Index on `photo_uid`, `subject_uid`
