# Albums repository + handler refactor

Replace the PhotoPrism-backed album endpoints with native Postgres-backed handlers. The frontend `Albums.tsx`, `AlbumDetail`, and album-membership widgets continue to use the same routes and payload shape.

## Requirements

### Files

- `internal/database/types.go` — add `Album` and `AlbumPhoto` types (or update if added by an earlier task).
- `internal/database/repository.go` — add `AlbumReader` and `AlbumWriter` interfaces.
- `internal/database/postgres/albums.go` — new file with implementation.
- `internal/database/postgres/albums_test.go` — tests.
- `internal/web/handlers/albums.go` — rewrite handlers.
- `internal/web/handlers/photo_albums.go` — rewrite (the "photo's album membership" handler).
- `internal/web/handlers/albums_test.go` — update tests.

### Types

```go
type Album struct {
    UID            string
    Slug           string
    Title          string
    Description    string
    Type           string  // album/folder/moment/state/month
    CoverPhotoUID  string
    Favorite, Private bool
    OrderBy        string
    CreatedBy      string
    CreatedAt, UpdatedAt time.Time
    PhotoCount     int     // computed in queries; not stored
}
```

### Interfaces

```go
type AlbumReader interface {
    GetAlbum(ctx context.Context, uid string) (*Album, error)
    GetAlbumBySlug(ctx context.Context, slug string) (*Album, error)
    ListAlbums(ctx context.Context, q AlbumQuery) ([]Album, error)
    ListAlbumPhotoUIDs(ctx context.Context, albumUID string) ([]string, error)
    ListAlbumsForPhoto(ctx context.Context, photoUID string) ([]Album, error)
}

type AlbumWriter interface {
    CreateAlbum(ctx context.Context, a *Album) error
    UpdateAlbum(ctx context.Context, a *Album) error
    DeleteAlbum(ctx context.Context, uid string) error
    AddPhotos(ctx context.Context, albumUID string, photoUIDs []string) error
    RemovePhotos(ctx context.Context, albumUID string, photoUIDs []string) error
    SetCoverPhoto(ctx context.Context, albumUID, photoUID string) error
}

type AlbumQuery struct {
    Type     string
    Favorite *bool
    Search   string
    SortBy   string  // "title" / "newest" / "oldest" / "photos"
    Limit    int
    Offset   int
}
```

UID format: `"a" + 16 random base32 lowercase chars`. Slug auto-derived from title (lowercase, ASCII-folded, spaces→`-`, dedup with `-N` suffix on collision).

### Endpoints to rewrite

All keep identical paths and payload shapes — only the implementation changes from `pp.*` to the local repo.

- `GET /api/v1/albums` → `ListAlbums` with query params (`q`, `type`, `favorite`, `sort`, `limit`, `offset`)
- `POST /api/v1/albums` → `CreateAlbum` (body: `{ title, description?, type? }`)
- `GET /api/v1/albums/{uid}` → `GetAlbum` (404 if missing)
- `PUT /api/v1/albums/{uid}` → `UpdateAlbum` (body: same shape as POST + `cover_photo_uid?`)
- `DELETE /api/v1/albums/{uid}` → `DeleteAlbum`
- `GET /api/v1/albums/{uid}/photos` → photo list filtered by `album_uid` (delegate to `database.PhotoReader.ListPhotos` with the filter; do NOT duplicate the photo SELECT logic)
- `POST /api/v1/albums/{uid}/photos` → `AddPhotos` (body: `{ photo_uids: [...] }`)
- `DELETE /api/v1/albums/{uid}/photos` → bulk remove ALL (body: `{}`) or specified UIDs (body: `{ photo_uids }`); preserve the current contract from `handlers/albums.go`
- `DELETE /api/v1/albums/{uid}/photos/batch` → `RemovePhotos` for the given UIDs
- `GET /api/v1/photos/{uid}/albums` → `ListAlbumsForPhoto`

JSON keys: snake_case, identical to the current PhotoPrism passthrough so the frontend keeps working. Look at the existing handler responses and `web/src/types/index.ts` for the exact shape — keep `photo_count` populated where the frontend reads it.

### Provider wiring

Add `AlbumReader()` and `AlbumWriter()` to the `Provider` interface, implement on the existing PG provider, inject into the `AlbumsHandler` struct.

### Tests

- Create + list + get + update + delete round-trip.
- Slug auto-generation handles collisions.
- AddPhotos is idempotent (re-adding the same UID does not duplicate the row).
- ListAlbumPhotoUIDs preserves `sort_order`.
- Cover photo setter validates the photo belongs to the album.
