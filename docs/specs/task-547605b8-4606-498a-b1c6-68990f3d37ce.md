# Slideshow TV / Presentation Mode

Add a presentation-quality fullscreen mode to the existing slideshow at `web/src/pages/Slideshow/`. The goal is something a user can confidently throw on a TV during a family gathering: minimal chrome, smooth transitions, optional Ken Burns motion, large-screen-friendly captions.

## Requirements

- A "TV mode" toggle button on the existing slideshow controls. When activated:
  - Enter browser fullscreen via the Fullscreen API.
  - Hide ALL UI chrome (nav, controls, page header). Cursor hides after 3 seconds of mouse inactivity and reappears on movement.
  - A minimal floating control bar fades in when the cursor moves (pause/play, prev, next, exit TV mode). Fades out after 3s of inactivity.
- Auto-advance with configurable delay (5s / 10s / 20s / 30s). Setting persisted in localStorage.
- Smooth cross-fade transition between photos (300ms).
- **Ken Burns effect** (optional toggle): slow pan + slight zoom across each photo's display duration. Direction alternates per photo (zoom-in/zoom-out, pan-left/pan-right) so the loop doesn't feel repetitive.
- **Caption overlay** (optional toggle): bottom-left semi-transparent strip with photo title/description + date in human format ("June 2024"). Large font, readable from across a room.
- Keyboard control everywhere in the slideshow (not only TV mode):
  - Space: pause/play
  - Left/Right: prev/next
  - Up/Down: speed slower/faster (cycles through the four presets)
  - F: toggle fullscreen TV mode
  - K: toggle Ken Burns
  - C: toggle captions
  - Esc: exit TV mode (browser already does this; ensure the app reacts and restores chrome)
- Wake lock: while TV mode is active, request `navigator.wakeLock.request('screen')` so the screen doesn't sleep. Release on exit. Gracefully no-op if unsupported.

## UI Details

- TV mode background: pure black (`#000`) to make photos pop on TVs in dim rooms.
- Letterbox photos (preserve aspect ratio) — no cropping.
- Ken Burns: CSS transform with cubic-bezier ease, max 1.15x scale, max 8% pan from center. Applied to a wrapper, not the `<img>` directly, so React reconciliation doesn't restart the animation on rerenders.
- Captions: `rgba(0,0,0,0.6)` background, white text, 24px font size base (scale up on larger viewports via `clamp`).
- Floating control bar: rounded pill at the bottom center, only icon buttons (no text labels), 56px tall touch targets so it works with a TV remote air-mouse.

## Implementation Notes

- Reuse `useSlideshow.ts` and `useSlideshowPhotos.ts`; add a `useTVMode.ts` hook that handles fullscreen state, cursor visibility, wake lock, and the auto-hide timer.
- The Ken Burns animation should be a CSS keyframe animation parameterized by direction + duration so it doesn't restart on photo change in a janky way.
- Test in headless Chromium with `--kiosk` flag mentally in mind — the result must look good without browser chrome.

## Edge Cases

- Fullscreen denied (browser permission): show an inline toast "Fullscreen not available" and fall back to a maximized in-page mode (hide app chrome via CSS, fixed-position black overlay).
- Wake lock unsupported (Safari historically): silent no-op, don't show errors.
- Photos with very different aspect ratios mid-show: Ken Burns must reset cleanly between photos.
- Pause must instantly stop Ken Burns (freeze on current frame), not just stop auto-advance.

## Out of Scope

- Chromecast / Cast API support (separate future task — TV mode via browser fullscreen on a connected TV / Pi / mini-PC is the v1 path).
- Background music.
- Per-photo dwell time overrides.
