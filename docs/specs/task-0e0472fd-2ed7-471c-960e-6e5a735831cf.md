# Markers + subjects repositories

Native Postgres-backed storage for face/region markers and subjects (people/pets). The existing pgvector `faces` table (512-dim ResNet100 embeddings) is unchanged and continues to act as the embedding cache — this task adds the relational marker/subject data that was previously read from PhotoPrism.

## Requirements

### Files

- `internal/database/types.go` — add `Marker`, `Subject` types.
- `internal/database/repository.go` — `MarkerReader`, `MarkerWriter`, `SubjectReader`, `SubjectWriter`.
- `internal/database/postgres/markers.go` and `subjects.go` — implementations.
- `internal/database/postgres/markers_test.go`, `subjects_test.go` — tests.

### Types

```go
type Marker struct {
    UID         string
    PhotoUID    string
    SubjectUID  string  // empty if unassigned
    Type        string  // "face" / "label"
    X, Y, W, H  float64
    Score       int
    Invalid     bool
    Reviewed    bool
    CreatedAt, UpdatedAt time.Time
}

type Subject struct {
    UID            string
    Slug           string
    Name           string
    Type           string  // "person" / "pet" / "other"
    Favorite       bool
    Private        bool
    Notes          string
    CoverPhotoUID  string
    PhotoCount     int  // computed
    FaceCount      int  // computed (markers count)
    CreatedAt, UpdatedAt time.Time
}
```

UIDs: markers `"m" + 16 base32`, subjects `"s" + 16 base32`.

### Interfaces

```go
type MarkerReader interface {
    GetMarker(ctx context.Context, uid string) (*Marker, error)
    ListMarkersForPhoto(ctx context.Context, photoUID string) ([]Marker, error)
    ListMarkersForSubject(ctx context.Context, subjectUID string, limit, offset int) ([]Marker, error)
}

type MarkerWriter interface {
    CreateMarker(ctx context.Context, m *Marker) error
    UpdateMarker(ctx context.Context, m *Marker) error
    DeleteMarker(ctx context.Context, uid string) error
    AssignSubject(ctx context.Context, markerUID, subjectUID string) error
    UnassignSubject(ctx context.Context, markerUID string) error
    SetInvalid(ctx context.Context, markerUID string, invalid bool) error
}

type SubjectReader interface {
    GetSubject(ctx context.Context, uid string) (*Subject, error)
    GetSubjectByName(ctx context.Context, name string) (*Subject, error)
    ListSubjects(ctx context.Context, q SubjectQuery) ([]Subject, error)
    ListSubjectsForPhoto(ctx context.Context, photoUID string) ([]Subject, error)
}

type SubjectWriter interface {
    EnsureSubject(ctx context.Context, name, subjectType string) (*Subject, error)
    UpdateSubject(ctx context.Context, s *Subject) error
    DeleteSubject(ctx context.Context, uid string) error
}

type SubjectQuery struct {
    Type      string
    Favorite  *bool
    Search    string
    SortBy    string  // "name" / "photos" / "newest"
    Limit     int
    Offset    int
}
```

`PhotoCount` for subjects is `COUNT(DISTINCT photo_uid)` from markers where `subject_uid = ? AND invalid = false`. `FaceCount` is `COUNT(*)` of same. Compute both in a single SELECT with a `LEFT JOIN`.

`GetSubjectByName` uses the existing `unaccent` extension + lowercase compare: `WHERE lower(unaccent(name)) = lower(unaccent($1))`.

### Tests

- Create marker + AssignSubject + ListMarkersForSubject.
- DeleteSubject cascades subject_uid → NULL on markers (already enforced by FK ON DELETE SET NULL, but verify in test).
- EnsureSubject is idempotent and accent-insensitive (Tomáš == Tomas).
- SubjectQuery sorts work.
