# Audit and refresh CLAUDE.md

`CLAUDE.md` is the in-repo guide for AI assistants (Claude Code) working in this codebase. It must precisely reflect the current architecture, env vars, endpoints, database schema, and developer workflows, because future AI sessions act on it.

## Scope

- File to edit: `CLAUDE.md` only.
- Source of truth: code under `cmd/`, `internal/`, `web/`, `Dockerfile`, `Makefile`, `docker-compose.yml`, `dev.sh`, `internal/database/postgres/migrations/`.

## What to verify and update

1. **Overview** — one-binary Go app + Postgres (pgvector) + external embeddings; PhotoPrism only retained for migration.
2. **Storage layout** — confirm `STORAGE_ORIGINALS_PATH` uses `YYYY/MM/<filename>` and the thumb cache uses `<cache>/thumb/<aa>/<bb>/<cc>/<hash>_<size>.jpg`.
3. **Bootstrap admin + user roles** — admin/editor/viewer; first admin auto-created from env vars; subsequent users via `/api/v1/users/*` or `users` CLI.
4. **Upload pipeline** — native handling of JPEG/PNG/WebP/TIFF/GIF; shells out to `heif-convert` (HEIC/HEIF), `dcraw` (RAW), `exiftool` (EXIF + XMP sidecar). Docker image bundles the Alpine `dcraw_emu` shim, `libheif-tools`, `exiftool`. Near-duplicate detection (pHash + embedding) gated by env vars.
5. **Build & test commands** — every command in the "Build and Test Commands" section must actually work (verify against the `Makefile`).
6. **Dev environment** — `dev.sh` script behavior, Postgres dev service, embeddings URL, fonts install via `make install-fonts`.
7. **API auth** — cookie-based session login flow.
8. **Architecture / packages** — every package listed under `internal/` must exist and the one-line description must match what the package actually does. Add any new packages (e.g. `internal/audit/`, `internal/imgedit/` if present) and remove any that were deleted.
9. **Configuration table** — env vars must match the current `internal/config/` loader. Cross-check against the schema in `internal/config/config.go` (or equivalent). Remove obsolete vars.
10. **AI providers + pricing** — confirm provider list, prompt files in `internal/ai/prompts/`, and the `prices.yaml` model coverage.
11. **REST API surface** — the list of endpoints in CLAUDE.md must match the routes wired in `internal/web/router.go` (or wherever Chi routes are mounted). Pay close attention to the most recently added endpoints: smart albums, share links, photo edits, audit log, trash, EXIF edit, mobile capture, build-thumbs admin job, db export/import, etc.
12. **Database tables** — the table list must match `internal/database/postgres/migrations/`. Every migration file should be reflected. Confirm column descriptions (especially for newer tables: `audit_log`, `photo_edits`, `smart_albums`, `album_share_links`).
13. **Frontend structure** — list of pages and shared hooks must match `web/src/pages/` and `web/src/hooks/`. Update with any newly added pages (Slideshow TV mode, SmartAlbums detail, etc.).
14. **Documentation Requirements** section — keep the file list aligned with the actual contents of `docs/`.

## Rules

- The code is the source of truth. If CLAUDE.md describes behavior that does not exist, fix or remove it. If the codebase has behavior not described, add a short note.
- Do NOT invent features, env vars, CLI flags, endpoints, packages, or tables. Grep before you write.
- Preserve the overall section structure; do surgical edits.
- Keep the file reference-style: terse, dense, scannable. Avoid prose.
- Where the file already links to `docs/*.md`, keep the link and let the linked doc carry the detail.
- Skim `git log --since="6 months ago" --oneline` for `feat:` and `refactor:` commits and verify the corresponding behavior is mentioned in CLAUDE.md.

## Done when

- Every package, env var, endpoint, table, page, and hook listed in CLAUDE.md exists in the codebase at the current commit.
- Every major feature added in the last 6 months is reflected (audit log, photo edits, slideshow TV mode, smart albums, share links, mobile capture, db-export/import, .deb release pipeline, near-duplicate upload scan, EXIF edit endpoint, trash + auto-purge, Czech full-text search, etc.).
- No dangling references to removed packages, env vars, or endpoints.
